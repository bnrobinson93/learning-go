Which values can call a method, which can satisfy an interface, and what survives a struct copy.

01Method sets

Embedding follows the same table: embed T and the outer value gets only T's value-receiver methods; embed *T and it gets all of them.

02Addressability

If an operand is addressable, Go auto-inserts & / * at a method call. This is a call-site convenience only — it never affects interface satisfaction.

AddressableNot addressable
variables
pointer dereferences *p
slice elements s[i]
array elements, if the array is addressable
fields of addressable structs 		composite literals T{}
map elements m[k]
function results f()
constants and most literals
string bytes s[i]

Mental test: could you write &x and get a pointer that stays valid? If not, it is not addressable.

03What a struct copy copies

Field kindAfter copying the struct
Scalar (int, string, …)Independent. Changes never cross.
MapHeader copied, table shared. m[k]=v crosses; m = … does not.
SliceHeader copied, backing array shared. s[i]=v crosses; s = append(…) may not.
PointerPointer copied, pointee shared.
Channel, funcReference copied; same underlying object.
Nested struct / arrayDeep-copied, field by field, recursively.
One-line version

Mutating through a reference field crosses the copy. Reassigning the field does not.

04Common failures, decoded

MessageCause
cannot call pointer method M on T The operand is not addressable. Assign it to a variable first, or take a pointer.
T does not implement I (method M has pointer receiver) Pass &v instead of v, or embed *T instead of T.
No error, but the mutation vanishes A copy was mutated: a range loop variable, a value receiver, or a value-embedded struct.

05Choosing a receiver

If…Use
the method mutates the receiver*T
the type contains a mutex or must not be copied*T
the type is large and copying is measurable*T
any other method on the type uses *T*T, for consistency
small immutable value, and none of the aboveT

Do not mix receiver kinds on one type without a reason — Code Review Comments: Receiver Type.
