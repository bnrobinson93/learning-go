# Notes

## Preferences

- **Code-first, quiz after.** Show the mechanism in real code, then test recall.
- Lessons must use code from Brad's own chapter exercises (`chN/main.go`), not
  synthetic examples.
- Brad deliberately makes exercises *harder* than the book asks in order to hit a
  concept head-on. Respect that: never suggest deleting the difficulty as the
  answer (e.g. "just make it a `string`"). Explain the mechanism instead.
- Every compiler claim in a lesson should be verified by actually compiling it
  first, and the exact error text quoted.
